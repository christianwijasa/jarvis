# Cloud Logging MCP

See [`docs/agents/mcp/cloud-logging.md`](../docs/agents/mcp/cloud-logging.md).

Call `cloud-logging` only if the named project's `project.yaml` lists it
under `mcp`. Other projects omit the key. Do not treat this server as
required for every Jarvis project.
